# Список покупок

Простое десктопное приложение на Python с интерфейсом Flet.

В приложении можно войти под логином, добавить товар в список, отметить покупку и удалить товар. Изначально в списке десять товаров. Товары выводятся по алфавиту.

При закрытии окна в папке `reports` создаётся файл `report.txt` с логином, временем входа и временем выхода.

## Запуск

Нужен Python 3.12.

1. Установить зависимости: `python -m pip install -r requirements.txt`
2. Запустить `main.py` в PyCharm.

## Файлы проекта

- `main.py` — запуск приложения.
- `app.py` — работа окон и обработка действий пользователя.
- `models.py` — описание товара.
- `storage.py` — хранение данных о сеансе без `dict`.
- `components.py` — собственные элементы интерфейса.
- `tests/` — проверки основных требований и отчёта.

## Проверка

```bash
python -m unittest discover -s tests -v
```
