# Список покупок

Я сделала небольшое десктопное приложение на Python с помощью Flet. В нём можно составлять список покупок, отмечать купленные товары и удалять ненужные.

## Что я реализовала

**Классы и ООП.** Я разделила программу на несколько файлов. Для товаров, хранения данных и приложения есть абстрактные классы, от которых наследуются `Item`, `PairStorage` и `ShoppingApp`. Для свойств добавила геттеры и сеттеры через `@property`. Также использовала специальные методы `__str__`, `__repr__`, `__eq__`, `__lt__` и другие. Благодаря сравнению товары можно сортировать по алфавиту.

**Своё хранилище.** По условию нельзя было использовать `dict`, поэтому я сделала класс `PairStorage`. Он хранит пары данных в обычном списке. Так сохраняются логин и время входа.

**Интерфейс.** Использовала Flet и создала 10 своих классов компонентов на основе стандартных: для текста, полей ввода, кнопок, галочек и расположения элементов.

**Список товаров.** Изначально в программе есть 10 товаров. Можно добавить новый, отметить купленным или удалить. Одинаковые товары повторно не добавляются. Список сортируется по алфавиту, а сверху показано количество всех и купленных товаров.

**Отчёт при выходе.** Когда закрываешь приложение, оно записывает в `reports/report.txt` логин, время входа и время выхода.

## Как запустить

Нужен Python 3.12.

Сначала установить библиотеки из `requirements.txt`:

`python -m pip install -r requirements.txt`

Затем запустить `main.py` через PyCharm или командой `python main.py`.

## Файлы проекта

* `main.py` — запуск программы.
* `app.py` — основная логика и обработка кнопок.
* `models.py` — класс товара.
* `storage.py` — хранение данных.
* `components.py` — 10 собственных компонентов Flet.
* `tests/` — тесты программы.
